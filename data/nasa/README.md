# NASA data used by AstroTrack

This folder holds **real, publicly available NASA data**. It is kept separate from
`data/simulator/`, which is **synthetic** demo data generated by `generate.py`.

| Time points | Pre-flight L-92, L-44, L-3 (days before launch); post-flight R+1, R+45, R+82, R+194 (days after return) |

### What AstroTrack uses
Only the `GLUCOSE` rows (28 values, mg/dL, with the lab's own reference range 65–99 mg/dL).
The backend serves them unchanged at `GET /api/nasa/inspiration4/glucose`, flagged
low / normal / high against **the lab's reference range from the file**.

### Limitations (please keep these when presenting)
- Samples were taken before and after flight, **not during** flight.
- Only 4 people and 7 time points each; not continuous monitoring.
- No heart rate, blood pressure, temperature, sleep or mood data. Those indicators
  in AstroTrack use **simulated** data (`data/simulator/`), clearly labelled.
- Research data, not a diagnosis of any crew member.
