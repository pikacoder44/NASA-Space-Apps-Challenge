# Responsibilities -- Research, Documentation & Presentation

## Role

**Research, Documentation & Presentation Lead**

## Overview

Responsible for researching the problem and supporting project planning,
while preparing and maintaining the team's key documentation and
presentation materials for the NASA Space Apps Challenge project.

## Key Responsibilities

### 1. Research & Problem Understanding

-   Research the selected NASA Space Apps challenge and understand its
    objectives, scope, and expected outcomes.
-   Study relevant background information, existing solutions, and
    potential approaches.
-   Identify useful NASA datasets, APIs, tools, and other credible
    resources for the project.
-   Share relevant findings with the team to support technical and
    product decisions.

### 2. Requirements Analysis & SRS

-   Help translate the challenge requirements and project idea into
    clear, understandable system requirements.
-   Prepare and maintain the **Software Requirements Specification
    (SRS)** document.
-   Document functional and non-functional requirements, assumptions,
    constraints, and project scope.
-   Coordinate with team members to keep requirements aligned with the
    proposed solution.
-   Prepare or organize supporting diagrams, such as use-case, class,
    and system architecture diagrams, where applicable.

### 3. Project Documentation

-   Create and maintain the project's `README.md` file on GitHub.
-   Document the project overview, problem statement, proposed solution,
    features, tools/technologies, and setup or usage instructions as
    information becomes available.
-   Keep project documentation organized, clear, and updated as the
    solution evolves.
-   Coordinate with developers to ensure technical details in the
    documentation are accurate.

### 4. Presentation & Slides

-   Prepare and organize the project presentation slides.
-   Present the problem, solution, key features, workflow, impact, and
    use of NASA resources in a clear and engaging way.
-   Coordinate with team members to collect accurate technical details,
    screenshots, and project updates.
-   Help ensure the final presentation follows the hackathon's
    submission requirements.

### 5. Team Coordination

-   Communicate documentation and research progress with the team.
-   Collect inputs and feedback from team members.
-   Keep track of pending documentation and presentation tasks.
-   Make revisions based on team feedback and project changes.

## Key Deliverables

-   Research notes and relevant references
-   Software Requirements Specification (SRS)
-   Supporting system/design diagrams
-   GitHub `README.md`
-   Presentation slides
-   Final documentation updates for project submission

## Collaboration

This role works closely with the development and design team. Technical
information, diagrams, implementation details, and project claims should
be reviewed with the relevant team members before final submission.

*Note: Responsibilities may evolve as the project develops and the team
