# Bundled data (copies)

Identical copies of the repo-root data files, kept inside `backend/` so a
deployment that only uploads the `backend/` folder (e.g. Vercel with Root
Directory = `backend`) still has them:

- `nasa/inspiration4/original/…CMP…csv`: NASA OSDR OSD-575, unchanged (sha256 dab247eb…4192a0c).
  Attribution and limitations: see `data/nasa/README.md` in the repo root.
- `simulator/mission_data.json`: SIMULATED mission data generated by `data/simulator/generate.py`.

If the repo-root files change, copy them here again.
